Welcome 👋

This wizard runs on the display itself. In the next few steps it will:

  • join your home WiFi,
  • connect to your email over IMAP — any provider that still allows password logins,
  • find your calendar over CalDAV, or follow any ICS link,
  • set your weather location, clock and refresh schedule,
  • let you add optional blocks from the store.

Each step is tested live before you move on, so problems show up here — not as a blank screen later. Nothing leaves the device: credentials are stored only in its internal flash.

1 · WiFi

Pick your home network (2.4 GHz only — the ESP32 can't see 5 GHz networks).

While the device joins your network its setup hotspot may drop for ~10 seconds. Stay connected to the setup WiFi — this page will recover by itself.
2 · Email (IMAP)
Type your address first — the provider below is picked for you when it's a known one.
Advanced (host, port, folder)
You can also skip email: leave the address empty and press Next.
3 · Calendar
Any standards-compliant server works — the device follows /.well-known/caldav to your calendar list, so your provider's plain domain is usually enough.
Any published iCalendar feed. Google Calendar: Settings → your calendar → "Secret address in iCal format".

6 · Store optional

Extras you can put on the screen next to the clock, weather, calendar and inbox. Blocks are data, not code: each one declares a web address to read and a widget to draw it with, and the device's fixed engine does the rest — nothing a block contains can execute. Signed blocks are checked against this device's trusted keys before they are stored.

Skip this entirely if you like — you can add blocks any time from the Blocks tab.

This device still runs the old single-slot (huge_app) partition table, which has no room for a second firmware copy — one last USB flash is needed to switch to the OTA-capable table. Follow the MIGRATING section of the FLASHING-*.txt in the CI artifact (your WiFi & settings survive; saved layout & installed blocks reset once). Every update after that works from this page.
The new image goes into the spare slot and is verified before the device switches to it — a failed or interrupted upload leaves the current firmware untouched. After flashing, the device reboots, redraws, and this editor window reopens by itself (give it ~1 minute).
